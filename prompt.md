# Prompt de Generación de Imagen

Este repositorio contiene el prompt utilizado para generar imágenes comparativas entre dos modelos de IA.

## Prompt Utilizado
> "A futuristic city with floating gardens and neon lights, cinematic lighting, hyper-realistic, 8k resolution, cyberpunk aesthetic."

## Modelos Comparados
1. **Modelo A**: Generación inicial.
2. **Modelo B**: Generación secundaria para comparación de estilo y detalle.
